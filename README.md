#  Car Price Prediction Dashboard

##  Project Overview
This project is a Machine Learning web application that predicts the price of a used car based on features such as year, mileage, and fuel type. It also includes an interactive Streamlit dashboard for user input and prediction.

---

##  Objective
To build a regression model that predicts car prices accurately and provides an easy-to-use interface for users.

---

## Dataset Features

| Feature     | Description                 |
|------------|-----------------------------|
| Year        | Manufacturing year of car   |
| Mileage     | Distance traveled (km)      |
| Fuel Type   | Petrol / Diesel             |
| Price       | Selling price (target)      |

---

##  Machine Learning Model
- Algorithm: Random Forest Regressor
- Type: Regression
- Libraries: Scikit-learn, Pandas, NumPy

---

##  Project Workflow
1. Load dataset  
2. Data cleaning and preprocessing  
3. Encode categorical variables  
4. Train regression model  
5. Evaluate model performance  
6. Save trained model  
7. Build Streamlit dashboard  
8. Predict car price using user input
